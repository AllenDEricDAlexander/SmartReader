# SmartReader PDF 阅读器需求描述

## 1. 产品定位

SmartReader 是一款面向桌面端的 PDF 阅读工具，采用 macOS 风格的轻量级 utility 布局，强调文档优先、阅读流畅、工具紧凑、状态清晰。

整体设计以 PDF 阅读为核心，提供本地 PDF 打开、阅读、搜索、跳转、缩放、书签、批注、最近文件、会话恢复、快捷键、缓存和桌面系统集成等能力。

---

## 2. 界面与布局

SmartReader 采用桌面工具型布局，包含以下界面结构：

* 顶部标签页，用于同时打开多个 PDF 文档。
* 紧凑型工具栏，用于展示常用操作入口。
* 可折叠侧边栏，用于承载书签、批注、搜索结果等辅助信息。
* 文档优先的主阅读区域，突出 PDF 内容本身。
* 窄窗口下自动简化工具栏，减少视觉拥挤。
* 整体风格采用温暖纸张质感的 macOS utility 设计，包括轻量 chrome、柔和背景、细腻文档阴影和响应式侧边栏行为。

---

## 3. PDF 打开方式

SmartReader 支持多种本地 PDF 打开入口：

* 通过浏览器文件选择器打开 PDF。
* 支持拖拽 PDF 文件到应用中打开。
* 支持通过 Tauri 原生文件选择对话框打开桌面本地 PDF。
* 支持桌面系统“打开方式”事件，用户可从系统文件管理器中直接用 SmartReader 打开 PDF。
* 支持 PDF 文件关联，作为系统 PDF 打开应用使用。
* 已经打开的桌面本地 PDF 路径再次打开时，不重复创建标签页，而是聚焦到已打开标签页。

---

## 4. PDF 文件读取与校验

PDF 阅读路径基于 EmbedPDF / PDFium，通过 blob URL 加载 PDF 内容。

对于桌面本地路径文件：

* 优先通过 Tauri fs 插件读取 PDF 字节数据。
* 提供经过校验的 Rust 读取 fallback，保证桌面路径读取稳定性。
* 打开前进行 PDF 文件合法性校验。
* 提取 PDF 页数元数据。
* 提取 PDF 大纲信息。
* 对 malformed 的大纲条目进行跳过处理，避免异常数据影响阅读器稳定性。
* PDF 大纲条目在可用时解析 PDF destination，并保留完整已解析大纲结构。

---

## 5. PDF 阅读与导航

PDF 的核心阅读、导航和控制能力交由 EmbedPDF 负责，SmartReader 不重复实现第二套 PDF 控制层。

EmbedPDF 负责以下能力：

* PDF 页面渲染。
* 页面跳转。
* 页码输入。
* 连续滚动阅读。
* 缩放控制。
* 适合页面、适合宽度等视图模式。
* PDF 大纲导航。
* PDF 缩略图导航。
* 文本选择。
* PDF 搜索结果定位。
* PDF 原生批注工具。
* PDF 工具栏与侧边导航区域。

SmartReader 只负责外层应用状态、标签页、最近文件、会话恢复、快捷键注册、缓存管理和阅读进度同步。

---

## 6. PDF 搜索

PDF 搜索使用 EmbedPDF 的搜索能力。

需求包括：

* SmartReader 的搜索入口可以打开 EmbedPDF 的 PDF 搜索面板。
* 浏览器选择打开的 PDF 和桌面路径打开的 PDF 均支持搜索。
* 搜索反馈使用 EmbedPDF 提供的 PDF 搜索状态。
* PDF 可见匹配结果由 EmbedPDF 管理。
* SmartReader 不额外渲染一套 PDF 搜索高亮层，避免与 EmbedPDF 状态冲突。

---

## 7. 阅读历史与前进后退

SmartReader 支持真实的 per-tab 阅读历史。

历史记录只针对明确跳转行为生成，包括：

* SmartReader 页码快捷跳转。
* 搜索结果跳转。
* 书签跳转。
* 历史后退 / 前进跳转。
* EmbedPDF 内部明确导航行为。

以下普通行为不产生历史记录：

* 鼠标滚轮滚动。
* 触控板滚动。
* 缩放。
* 在搜索框中输入。
* 偏好设置修改。
* 普通阅读进度变化。

PDF 连续滚动场景下，普通滚动只更新阅读进度，不视为硬导航。

---

## 8. 缩放与触控板支持

PDF 阅读器支持触控板 pinch 风格缩放。

需求包括：

* 在 PDF 阅读视口内识别触控板缩放操作。
* 将 SmartReader 请求的缩放比例同步到 EmbedPDF。
* 缩放比例受 SmartReader 现有阅读器缩放范围限制。
* 缩放行为不产生阅读历史记录。
* 工具栏状态需要及时反映当前缩放状态。

---

## 9. 批注能力

SmartReader 支持基于 EmbedPDF 的 PDF 原生批注能力。

批注 MVP 包括：

* 高亮。
* 下划线。
* 删除线。
* 波浪线。
* 红色文字。
* 文本笔记。
* 区域批注。
* 批注颜色设置。
* 线条粗细设置。
* 笔记字体设置。
* 学术标签。
* 单条批注可见性控制。
* 批注过滤。
* 批注搜索。
* 自动会话 / 缓存持久化。
* PDF 原生批注 JSON 导出。
* PDF 原生批注 JSON 导入。
* SmartReader 管理的笔记支持 Markdown 导出。
* 支持 macOS PDFKit managed-copy 同步开关。

---

## 10. 书签与辅助侧边栏

SmartReader 侧边栏支持 PDF 相关辅助功能：

* 书签列表。
* 批注列表。
* 搜索结果列表。
* 当前文档阅读状态。
* 可折叠侧边栏。
* 窄窗口下自动收起或简化显示。

PDF 大纲和缩略图导航由 EmbedPDF 内部负责，SmartReader 不渲染并行的 PDF 大纲面板或缩略图面板。

---

## 11. 最近文件库

SmartReader 提供 grid-based 最近文件库，用于管理已打开 PDF。

最近文件库需求包括：

* PDF 最近文件网格展示。
* pinned / favorite 过滤。
* 阅读进度展示。
* 上次阅读位置展示。
* 文件元数据展示。
* 延迟 hover 摘要卡片。
* 文件路径仅在 hover 时显示，避免界面过度暴露路径信息。
* 打开前支持点击进入详情面板。
* 最近文件保存轻量级恢复元数据。
* 重新打开桌面本地 PDF 时，恢复上次保存的页码位置。
* 已经打开的桌面路径文件再次打开时，聚焦已有标签页。

## 13. 分类级加密

SmartReader 支持分类级最近文件元数据加密。

加密保护范围包括：

* SmartReader 管理的最近文件元数据。
* 分类元数据。
* 标签元数据。
* 可恢复会话条目。
* 缓存元数据。
* 搜索元数据。

加密分类需要支持以下可靠性路径：

* 解锁。
* 移动。
* 删除。
* 清理。
* 保留策略淘汰。
* 重新密封。
* 存储原子化 reseal。
* 失败 reopen 记录清理。

## 14. 会话恢复

SmartReader 支持桌面 PDF 会话恢复。

恢复范围包括：

* 桌面路径标签页。
* 当前激活标签页。
* 侧边栏状态。
* 用户偏好设置。
* 书签。
* 批注。
* 缩放比例。
* 每个文档的阅读位置。
* 每个标签页独立的阅读进度。

切换标签页时，每个 PDF 保持自己的最后阅读页码和阅读状态。

## 17. 缓存与性能

SmartReader 需要优化大文件 PDF 打开和重复加载性能。

需求包括：

* 打开标签页运行时 reader 缓存。
* EmbedPDF blob URL 缓存。
* 缓存持久化防抖。
* 桌面文档异步读取。
* 避免重复读取大型 PDF。
* 减少切换标签页时的重新加载。
* 保持大文件阅读响应性。

## 19. 状态反馈与可用性优化

SmartReader 需要提供清晰的阅读状态反馈：

* 标签页展示阅读进度。
* 工具栏展示当前状态。
* PDF 页码状态清晰可见。
* 最近文件展示进度和元数据。
* 文件加载状态明确。
* 搜索状态明确。
* 窄窗口下布局自动调整。
* EmbedPDF 的浅色 / 深色主题需匹配 SmartReader 的温暖 utility 配色。

---

## 20. 功能边界

SmartReader 专注于 PDF 阅读体验，不重复实现 EmbedPDF 已提供的 PDF 控制能力。

具体边界：

* PDF 工具栏由 EmbedPDF 负责。
* PDF 大纲由 EmbedPDF 负责。
* PDF 缩略图由 EmbedPDF 负责。
* PDF 搜索结果可见状态由 EmbedPDF 负责。
* PDF 批注底层能力由 EmbedPDF 负责。
* SmartReader 负责外层应用壳、文件管理、最近文件、缓存、会话、快捷键、偏好设置和桌面系统集成。

核心原则是：PDF 阅读控制交给 EmbedPDF，SmartReader 做桌面级阅读管理与体验增强。
