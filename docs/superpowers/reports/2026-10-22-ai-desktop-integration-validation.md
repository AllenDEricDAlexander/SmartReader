## 修复内容

- 阿里云配置没有 embedding 模型时，编辑表单保持为空；推荐型号只保留为输入提示。修复前桌面复现：保存聊天配置后自动填入 `text-embedding-v4`，随后“验证连接”被错误禁用。修复后保存成功即可验证聊天连接。
- 答案与思考内容各自使用流式脱敏缓冲，覆盖 API Key 被拆成多个 delta 的情况；正常结束释放普通尾部，失败或取消不释放待判定的凭据前缀。
- embedding 只对 HTTP 413 或明确的批量大小限制缩批，按实际输入数递减；401/403/404/429/503、网络、超时和普通模型错误直接失败，单条输入不会重复发送。
- 流式内容仅在接近底部时自动跟随，上滚暂停跟随；页头置顶，提供“回到最新回答”和生成中的“取消回答”。
- 已完成回答后提供“继续提问”，保留草稿并聚焦原输入框，按页头实际高度定位，为问题标签预留空间。
- 直接聊天使用对应的发送、等待与空状态文案；Milvus 缺少 embedding 模型时明确解释不可检索的原因。
- 本地 QA 服务增加 `qa-long` 模型，用 24 段合成文字复测滚动、追问和取消。

沿用现有组件、AI transport、错误类型和存储边界。局部状态与直接函数足以解决这些问题，没有增加设计模式或额外抽象。
