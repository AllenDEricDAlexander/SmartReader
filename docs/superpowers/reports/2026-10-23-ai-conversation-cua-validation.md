# AI 会话管理原生 UI 复测

## 环境与边界

- 按用户要求使用 computer use 操作实际 macOS Tauri 应用；未以浏览器或组件测试代替桌面验收。
- QA 应用标识为 `com.smartreader.cuaq20261023a`，使用全新、独立的应用数据目录。未安装或覆盖 `/Applications/SmartReader.app`，未操作正式聊天和文献数据。
- 使用仓库 `scripts/qa/mock-ai.mjs` 的本机兼容接口与公开假密钥。没有调用真实厂商、上传用户文献或验证真实模型质量。
- 保留 `src-tauri/gen/schemas/capabilities.json` 的原有改动；构建后与测试前备份逐字比较一致。

## 发现并修复

1. **元数据保存重置阅读位置。** 原生复现：在 24 段长回答中向上阅读至第 1–3 段，点击置顶，正文跳回第 19–24 段。原因为通用 `conversationBusy` 导致正文组件卸载。修复后将真正的活动会话切换与元数据保存区分；保存期间保留正文、滚动和展开状态，同时禁用输入、发送与配置，避免并发保存丢失编辑。真正切换会话和加密锁定仍等待正确恢复。
2. **首屏输入框被配置内容挤出。** 压缩页头、厂商与模型工具栏及重复说明，将输入和发送放到知识库管理之前。知识库与分组管理按需展开，历史列表常驻搜索，卡片分层显示标题、轮数、时间及操作，保留键盘和拖拽操作。
3. **紧凑工具栏标签竖向断字。** 原生 125% 截图发现“厂商”“模型”被压成两行，补充禁止标签收缩和选择器弹性宽度。最终亮色与暗色截图确认文字横向显示。
4. 布局审查收尾：分组保存状态放在折叠面板外，收起后仍可看到失败；可见标题与无障碍名称一致；展开区有方向提示；未添加依赖或持久化字段。
5. **长历史列表的删除确认不可见。** 原生复现：滚动到底部点击删除，确认区域插在列表上方，当前视野仍停在底部。修复后确认区域自动进入视野，默认聚焦安全的“取消”；键盘取消后恢复原滚动位置与原删除按钮焦点，不改变当前聊天。已在同一 QA 数据上重新构建并用原生窗口验证。

沿用现有组件、原生表单、主题变量与 SQLite 存储服务。局部状态和直接条件判断足够，没有引入额外设计模式或抽象。
