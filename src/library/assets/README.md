# Notes PDF font

`NotoSansSC-Regular.ttf` is the 400-weight static instance of [Noto Sans SC](https://github.com/google/fonts/blob/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf), generated with fontTools 4.67.0 using `fontTools.varLib.instancer` with `wght=400`. The source font is distributed under the SIL Open Font License in `OFL-NotoSansSC.txt`.
